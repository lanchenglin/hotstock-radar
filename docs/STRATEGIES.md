# 策略规则与使用边界

当前代码核心为 `hotstock/engine.py`，规则实现继承0.1基线；整体产品与新增消息联动以 [PROJECT_OUTLINE.md](PROJECT_OUTLINE.md) 为准。

两类研究：主线扩散后的首次突破、强势趋势回撤后重新走强。共同前提是已确认交易日历、可验证当日行情时间、足够完整的历史、题材成员覆盖与已知成员时间。候选的入场上限、初始止损和参数快照冻结，不随股价上涨不断抬高追价范围。

`can_execute` 是程序的数据与规则符合状态，不保证成交，也不是获利概率。DEMO永远不用于实际执行。当前腾讯＋BaoStock标准报价缺少权威当日涨跌停价、最小买入单位和停牌状态，严格就绪条件会阻断；不要关掉质量检查来伪造实盘可用性。

本版消息风险是额外的展示/创建计划闸门：相关事件含风险关键词且待核实/跟踪时，可阻断新增计划和候选界面入场状态。它不会更改底层冻结计划的价格、账本、实际成交或原价格止损。底层行情审计与消息审计分开保存，因此导出时应同时查看事件状态，而不能仅根据原始行情计划状态认定消息风险已经解除。

仓位公式基于明确的账户参考值、计划风险、费用/滑点、交易单位及同题材敞口。缺失字段不推算具体股数。账本为人工确认的外部成交，不等同于券商实时余额。

逐批次T+1可卖量、价格结构失效、时间失效、移动保护、题材转弱和集中度提醒保留。提醒触发不代表委托或成交；实际执行还受交易限制、跳空、跌停与流动性影响。算法没有经过真实历史收益和样本外有效性验收，禁止展示未经验证的胜率或收益。
