### 本轮修复并覆盖的关键问题

1. 多题材股票逐个题材计算剩余额度，不只按第一条概念标签计算仓位。
2. 买入时间格式虽不同，也转到中国时区后排序，避免 FIFO 次序错误。
3. 已有计划、成交或高点的历史/演示工作区不得把时间倒回；另一次研究使用新的独立数据目录。
4. 非演示快照不能通过自报未来 as_of 绕过未来行情检查。
5. 新旧持仓批次分别受 T+1 限制；超量卖出失败不会先扣现金或部分写入账本。
6. 切换供应商不能将 Tushare 的 Token 或地址沿用到普通 HTTP 数据源。
7. 采集失败保留明确错误和最后数据时点，不自动加载演示数据。
